# Søreide G2015 – kampapp

Lagoppstilling, bytter og spilletid for Søreide fotball gutter 2015.

## Bruk
- **Tropp:** hele laget ligger i spillerbiblioteket. Huk av de som skal spille dagens kamp.
- **Kamp:** velg spillform og formasjon, trykk «Fyll opp laget», og start klokken.
- Dra spillere for å flytte eller bytte, eller trykk på én spiller og så på en annen.
- «Neste bytte» foreslår hvem som bør inn og ut ut fra spilletid.

Kampen og valgt tropp lagres på mobilen som brukes.

## Endre faste spillere
Åpne `index.html`, finn `DEFAULT_ROSTER` og legg til, fjern eller rett navn og draktnummer.
Last opp filen på nytt, så får alle trenerne de faste spillerne. Spillere en trener har lagt til på sin egen mobil, blir liggende i tillegg.
